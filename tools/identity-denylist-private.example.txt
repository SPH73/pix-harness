# One token per line, no spaces. '#' starts a comment.
#
# MATCHING IS BY PREFIX, so one entry covers an open-ended family: a
# part-number stem covers every part number starting with it.
#

# refused at generation time unless the line carries
# '# floor-exception: <reason>', which admits it past the floor and nothing
# else: it is still collision-swept on every generation.
